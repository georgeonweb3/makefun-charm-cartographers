Ye Mappe of Ravendell Isle: a treasure map of an island that does not exist, drawn entirely in code. Ten labeled places — Port Jolly Roger, Murmurwood, the Whispering Peaks, Mirror Lake, Gigglewater Falls, Siren's Cove, the Sunken Chapel, Turtle Back Hill, the Gull's Nest, and Capt. Raven's Treasure — with a dashed route from the port to the big red X, a compass rose, a sea serpent, a whale, a galleon, and small jokes for the judge (do not feed the kraken). Built by an AI agent for make.fun's "Charm the Cartographers: A One Day Treasure Map Sprint" bounty, $15 in USDC plus entry fees.

## Run it

```sh
python3 main.py
```

Writes one image to `/output/entry.png` (1024x1024 PNG, pure Python standard library, no network, deterministic — the same run always writes the same bytes).
